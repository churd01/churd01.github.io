
# Claire Hurd Personal Portfolio Website

This is a personal portfolio website created by, myself, Claire Hurd. It showcases my work as a theatre artist and manager, and includes information about my projects, skills, and experience. The website is designed to be visually appealing and easy to navigate, with a focus on showcasing my work in the best possible light.

## Installation or Setup Instructions

### Local Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/churd01/churd01.github.io.git
   cd churd01.github.io.git
    ```

2. Open the `index.html` file in your web browser to view the website locally.
3. To make changes to the website, open the HTML, CSS, and JavaScript files in your preferred code editor.
4. Save your changes and refresh the browser to see the updates.

### Deployment

1. The website is hosted on GitHub Pages. To deploy your own version, follow these steps:
   - Create a new repository on GitHub.
   - Clone the repository to your local machine.
   - Copy the contents of this repository into your new repository.
   - Push the changes to GitHub.
   - Enable GitHub Pages in the repository settings.
    - Your website will be available at `https://<your-username>.github.io/<repository-name>/`.
2. To update the website, make changes to the files locally and push the changes to GitHub.
    ```bash
    git add .
    git commit -m "Update website content"
    git push origin main
    ```
3. The website will automatically update on GitHub Pages.

## Usage Instructions

- Navigate to different sections using the navigation bar:
    - Resume
        - Provides a viewable and downloadable PDF of my resume.
    - About Me
        - A brief introduction about myself and my background.
    - Portfolio
        - A showcase of my work, including images and descriptions of each project.
    - Senior Project
        - A pdf view of my senior project.
- View current and upcoming projects in the home page.
- Click contact buttons at the bottom of the page to initiate a call or send an email.
